============================================================
RASPI NICE SETUP — V1
============================================================

Purpose
-------
Adds quality-of-life configuration to a Raspberry Pi dev box
after running raspi-bootstrap.

This layer configures:

- Starship prompt
- Conda prompt behavior
- Nerd Font (FiraCode Nerd Font)
- Bash shortcuts
- ~/.bashrc.d loader
- Global gitignore
- Minimal tmux configuration

Run
---

curl -fsSL https://raw.githubusercontent.com/<USER>/<REPO>/main/extras/raspi-nice-setup_v5.sh | sudo bash


What It Does
------------

1. Installs Starship into:
   ~/.local/bin

2. Writes:
   ~/.config/starship.toml

3. Appends guarded blocks to:
   ~/.bashrc

4. Creates:
   ~/.bashrc.d/pi-nice.sh

5. Sets:
   conda changeps1 = False
   (prevents conda from altering PS1)

6. Installs FiraCode Nerd Font (user-local):
   ~/.local/share/fonts/FiraCodeNerdFont

7. Writes global gitignore:
   ~/.config/git/ignore

8. Writes minimal tmux config:
   ~/.tmux.conf


Important
---------

• The Nerd Font must also be installed on the machine rendering the terminal
  (your laptop) if accessing the Pi via SSH.

• If icons show as boxes:
    - Install Nerd Font locally
    - Set your terminal font to “FiraCode Nerd Font”
    - Restart terminal


Verification
------------

Open new shell and verify:

starship --version
git config --global core.excludesfile
tmux -V
echo "  ➜"

If glyphs render correctly → setup is complete.
